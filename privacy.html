Política de Privacidade

Última atualização: setembro de 2026.

O "Assistente Pessoal" é um projeto de uso estritamente pessoal, desenvolvido e utilizado por uma única pessoa (o próprio desenvolvedor). Não é distribuído, vendido ou disponibilizado para terceiros.

Quais dados são acessados

Quando conectado à conta Google do próprio desenvolvedor, o assistente pode acessar, apenas para uso pessoal:

  • Leitura e busca de e-mails no Gmail (somente leitura).
  • Listagem, leitura e envio de arquivos no Google Drive.

Como os dados são usados

Esses dados são usados exclusivamente para responder a pedidos feitos pelo próprio desenvolvedor através de um bot pessoal no Telegram (por exemplo: "busque meus e-mails não lidos" ou "liste meus arquivos recentes do Drive"). Nenhum dado é compartilhado, vendido, publicado ou usado para treinar modelos de terceiros.

Armazenamento

O conteúdo das interações fica armazenado localmente, em um banco de dados no computador do próprio desenvolvedor, e não é enviado a nenhum serviço além da API da Anthropic (Claude), usada para gerar as respostas, e das APIs do Google (Gmail/Drive), usadas apenas para executar os pedidos feitos pelo próprio usuário.

Compartilhamento com terceiros

Este projeto não compartilha, vende ou divulga dados pessoais a terceiros. Não há anúncios, rastreamento ou coleta de dados de outros usuários — porque não há outros usuários.
